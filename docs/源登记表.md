# 源登记表

> 本表是「有哪些源、各自什么等级、当前开放多少工具」的唯一真相。
> 工具用法见 [README](../README.md)；新增源的步骤见 [新增一个源](新增一个源.md)。
> 工具数由 `npm run counts` 从运行时注册表读取，本表数字必须与它一致（`npm run check:counts` 会拦不一致）。

## 等级口径

| 等级 | 判据 | 当前处理 |
|---|---|---|
| **T1** | 有文档化的 JSON 接口（OpenAPI / REST 文档 / 官方 curl 示例），且至少两个端点实测可用 | 可接入并写工具 |
| **T2** | 有稳定的参数化 URL，但拿不出 API 文档 | 可接入；正文必须写明接口未文档化、字段可能漂移 |
| **T3** | 只有网页 / 需要登录 / 有反爬或访问控制 | **不接入**，不绕过访问控制 |

## 各源的覆盖与边界（摘要）

完整工具清单与逐工具限制见 [README](../README.md)。

- **WheatOmics**：封装了已知基因、表达、文献、ID 换算、跨物种同源、共线、PPI、调控区、GO/KEGG 富集、变异目录与区间查询、按基因取序列、Pfam 注释。不同端点使用不同代次的基因编号（01G/02G/03G），工具正文会写明实际使用的代次；「返回 0」不等于「不存在」。
- **Strawberry**：目录、精确基因注释、已证实数据集的表达、TF 成员与共线。表达保留上游 batch-corrected TPM，不跨数据集比较。
- **GWH / ICG / IC4R**：NGDC 公开接口。IC4R 只覆盖粳稻（japonica）；ICG 不提供名称搜索；GWH 的下载路径不代表已验证可下载。
- **Gramene**：全文检索、基因、差异表达、分类单元；实测物种有限，不声称覆盖整个禾本科。
- **SCOD**：甘蔗；区间查询只返回**完全落在区间内**的基因，`0` 条不代表该位置没有基因。
- **Ensembl Plants**：只开放拟南芥、水稻、小麦、玉米四个物种；「查无」在上游是 HTTP 400，工具按端点、请求身份与原体三重锚定后才判未找到。
- **STRING**：必须显式给 `species`；不传时上游会跨物种解析。`score` 缺失显示「未提供」，不倒成 0。
- **UniProt**：只开放拟南芥、小麦、水稻、玉米四个物种；不返回序列本体、不做比对、不分页。
- **InterPro/Pfam**：参考数据集源，按 Pfam accession 取 HMM 域模型，不提供物种组学数据。

## 不接入的源

需要登录、需要过 Cloudflare 或只有网页表单的源一律不接入；本仓不绕过访问控制，也不镜像数据。
某一源暂时不可达时，`npm run probe` 会单独报出，不影响离线测试。
